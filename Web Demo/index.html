About this model and how to use it

Purpose. Estimate the probability that a monsoon season contains at least a specified number of consecutive dry days, and the mean longest dry spell.

  • Data basis: the notebook uses daily ERA5 precipitation retrieved through the Open-Meteo Historical Weather API, from 1 December 1990 to 30 September 2020, for Colombo and Hambantota.
  • Classification: a day is wet when rainfall is at least 1.0 mm; otherwise it is dry. The state coding is D = 0 and W = 1.
  • Season definitions: SWM is May–September (153 days). NEM is December–February; the notebook sets its simulation length to 90 days although observed blocks span 90–91 days.
  • First-order chain: tomorrow's wet/dry state depends on today's state. The initial day is sampled using the historical first-day wet frequency for the selected location and season.
  • Second-order chain: tomorrow's state depends on the previous two days. The first two days are sampled from the historical DD, DW, WD, WW pair frequencies.
  • Monte Carlo: each simulated season is independent conditional on its sampled initial state/pair. The browser uses a seeded pseudorandom generator; its random stream is not NumPy's, so exact bit-for-bit results are not expected.

Use: choose location, season, model order, dry-spell threshold and simulation count. Press Start; Pause suspends the run and Start resumes it. Reset clears the results and restores the seeded random stream. At completion, compare the estimated probability with the notebook benchmark where available.

Reproducibility target: for first-order simulations with a 7-day threshold and 200,000 seasons, the estimate should be close to the notebook's reported first-order Monte Carlo estimate. The demo uses an absolute tolerance of 0.002 for its benchmark flag. Different pseudorandom streams and the notebook's 20-seed averaging mean exact equality is neither expected nor required.

Scope: this interactive page reproduces the notebook's wet/dry Markov-chain dry-spell analysis. The notebook's separate Gamma-distributed wet-day rainfall-amount model is not simulated in this page.
